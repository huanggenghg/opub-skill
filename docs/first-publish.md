# 第一次用本地 AI Agent 发布：opub 新手教程

本教程适合经常向至少两个平台发布、已有本地 AI Agent 的创作者或运营。Agent 必须能在你的电脑执行命令、读取你指定的素材，并打开本地浏览器。仅能网页聊天的 AI 不足以完成这套流程；不同 Agent 的技能入口不同，请按其说明导入，不假设存在通用的一键安装协议。

opub 支持抖音、小红书、快手、B站、视频号、百家号和微博。七个平台均支持视频；图文支持抖音、小红书、快手。配套演示使用 WorkBuddy 发布到抖音和 B站，具体账号和设备仍需你自己验证。

## 1. 先确认电脑与费用

需要 CPython 3.11、3.12 或 3.13，以及 macOS arm64/x86_64、Windows x86_64 或 Linux x86_64。缺少 Python 时，需要先准备受支持的解释器；技能不提供或管理 Python，不能承诺 Agent 会包办全部环境配置。

安装、环境修复和发布预检无需许可，也不会发布。真正发布需要激活：0.x 创始版 ¥9.90，首次兑换绑定一台设备，不迁移、不解绑、不提供换机重置，新电脑重新购买。许可覆盖 0.x，已安装的 0.x 版本可永久离线使用，未来大版本需另购。购买前看清这项设备限制。

工具在本地运行，从你指定的路径读取素材；账号登录信息、许可和发布记录保存在电脑的 `~/.opub/`。不要把该目录或登录快照上传到聊天、公共仓库。

## 2. 给 Agent 最新完整技能

打开[公开技能仓库](https://github.com/huanggenghg/opub-skill)，进入 `SKILL.md`，复制完整内容，通过 Agent 支持的技能导入方式或聊天输入交给它。不要只复制安装命令或零散段落。本教程核对版本为 0.9.7；后续安装以仓库最新完整技能为准。

随后复制这段任务给 Agent：

> 请遵守我提供的完整 opub 技能，先检查本机系统、CPU 和 Python 是否受支持，再安装 opub 并准备浏览器环境。只做安装与环境检查，不购买、不登录、不发布。若缺少 Python 或没有匹配的编译包，请告诉我具体缺项；不要改装源码包。检查完成后告诉我环境是否就绪，并等待我提供发布输入。

首次安装可能需要下载依赖和浏览器。B站还需显式准备 biliup，Agent 应按技能执行 `opub --repair-env --with-bilibili`；图文转视频另需可选依赖和系统 ffmpeg，首次可先用现成视频。

## 3. 用自己的素材做预检

准备一条你有权发布的视频或一组图片。提供完整文件路径、目标平台、标题、描述、话题标签；不使用的描述或标签明确说“留空”。建议首次选两个平时常用的平台，使用即时发布。

复制下面任务，并在同一条消息里逐项写出你的实际输入：

> 以下是我提供的素材完整路径、目标平台、标题、描述和标签。请逐项复述让我确认，不自行搜索素材或改写文案。确认后只运行 dry-run 预检，给出环境与输入是否通过的结论，暂不付款、不登录、不发布。预检成功只是计划可执行，不算发布成功。

写完五项后确认复述。预检失败时先修复，再继续；无需为了检查环境提前购买。没有匹配安装包时应换用受支持的系统与 Python 组合，不能去掉编译包限制。

## 4. 确认发布，自行付款和扫码

预检通过且输入确认无误后，向 Agent 明确说：“确认以上输入，现在执行真实发布。”Agent 会检查许可；首次未激活时按技能打开购买页，也可从[官网](https://opub.cn)进入购买入口。

在你自己的浏览器完成手机号或邮箱验证、支付。付款后复制爱发电发放的激活码，让本地 Agent 按完整技能兑换；要求它不展示完整码、不写入可见消息或日志。不要交给 Agent 验证码、爱发电密码或支付账户资料，也不要把激活码贴到公开聊天或报错反馈中。激活成功后自动继续同一个已确认任务。

平台需要登录时会弹出浏览器窗口，你本人按界面扫码。Agent 不能代替你登录，也不需要你导出 Cookie。正常发布可能无可见浏览器窗口；不要因为暂时没有进度消息就再启动一次。

## 5. 核对各平台作品，再判断是否完成

结束后应收到各平台成功或失败、错误码与建议，以及可获得的作品链接。打开链接，核对账号、素材、标题和发布时间，再检查是否可公开访问或播放。平台仍在审核时，以后台状态为准，不能把“提交成功”当成“已经公开可播放”。

成功但没抓到链接时，到自己的创作者后台寻找本次作品；不要仅为取链接再次发布。保存 Agent 返回的任务编号 `run_id`，以后继续同一任务时用恢复流程，已成功项应复用已有记录。

如果超时、中断或出现 `RUN-004`，先人工核对平台。结果未知不得自动重发，不要删除发布记录来绕过保护。可给 Agent：

> 请恢复刚才记录的 run_id，不重跑普通发布命令、不修改原输入。遇到结果未确认的项先停止重发，告诉我需要在哪个平台人工核对。

## 6. 卡住时提供最少信息

反馈电脑系统与 CPU、Python/opub 版本、本地 Agent 名称、目标平台、卡在安装/预检/激活/发布哪一步、稳定错误码与简短现象。发布中断可补充 `run_id`，素材路径先去掉私人目录信息。不要提供 Cookie、验证码、密码、激活码、设备标识或未经脱敏的完整日志。

首次作品核验通过后，下一次有真实发布需求再使用；记录最卡的一步和一周内是否复用，比额外做无用的测试更有帮助。
